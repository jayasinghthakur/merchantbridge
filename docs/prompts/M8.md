# M8 Proof + evidence (Tier 2, ~1 day)

**Goal:** independent proof that the connector works from Anthropic's infrastructure and on real Zoho data, plus a
security suite a reviewer can read.

**Read first:** `docs/notes/anthropic-mcp.md` §7 (MCP connector beta), `docs/notes/mcp-v2.md` §5-7,
`docs/adr/0003-*.md`, `docs/adr/0004-*.md`, `evals/**`, `packages/core/src/stores.ts`, `apps/api/src/config.ts`
(`MB_TRUSTED_EGRESS_CIDRS`).

**Tests first (red):**

- Security suite (`apps/api/test/security.test.ts`): tenant A's key cannot read tenant B (DB, cache and governor keys);
  `/mcp/demo` and `/api/playground` cannot resolve a live tenant even with a forged header; no tool input schema has a
  URL/path field; every upstream request in the contract suite is GET; no token, auth code or client secret appears
  in captured logs or responses; `allowedHosts` rejects an unknown Host.
- Fixture tests: recorded trial-org fixtures (PII-scrubbed) pass the unchanged contract suite.
- Proof route: response contains `mcp_tool_use` + `mcp_tool_result` blocks for `server_name: 'merchantbridge'`
  (Anthropic client stubbed in unit tests).

**Build:**

- "Proof" toggle: `/api/playground` variant that calls `beta.messages.create` with `betas: ['mcp-client-2025-11-20']`,
  `mcp_servers: [{ type: 'url', url: $API_URL/mcp/demo, name: 'merchantbridge' }]`,
  `tools: [{ type: 'mcp_toolset', mcp_server_name: 'merchantbridge' }]`; trace renders the server-side tool blocks.
- `scripts/record-fixtures.ts` (human-run, GET only, scrubs emails/phones/addresses/notes)
  -> `packages/zoho-inventory/test/fixtures/live/`.
- Agent SDK eval runner against the deployed `/mcp/demo`; grow evals to 30; `/evals` page shows published pass rates.

**Out of scope:** OAuth 2.1 on the MCP leg, connector #2, conflict checks (Tier 3).

**Done when:**

- `pnpm --filter @mb/api test && pnpm --filter @mb/zoho-inventory test && pnpm lint && pnpm typecheck` green.
- Proof toggle on prod returns an answer whose trace shows `mcp_tool_use` from Anthropic's side, and `/mcp/demo`
  logs show the request arriving from the trusted-egress bucket.
- `pnpm evals` (30 evals, both models) report committed; `/evals` page live.

**Commit:** `test(api): security suite (red)`, `feat(api): proof toggle via mcp connector`,
`test(zoho): recorded live fixtures`, `feat(evals): agent sdk runner and 30 evals`.
