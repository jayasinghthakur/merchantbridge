# M3 Governor (1/2 day)

**Goal:** every Zoho call is rate-, concurrency-, budget- and circuit-controlled per org, shared by all agents.

**Read first:** `packages/core/src/governor.ts` (interfaces + `zohoRateProfile`), `packages/core/src/kv.ts`,
`packages/core/src/clock.ts`, `docs/adr/0005-*.md`, `docs/notes/zoho.md` §7-8, existing `packages/governor/src/**`.

**Tests first (red, ManualClock + MemoryKv, no real timers):**

- 81st request in a minute queues; queue > 10 s -> `RATE_LIMITED` with `retry_after_s`.
- Concurrency: 5th in-flight call on a free plan waits; a crashed holder's lease expires after 30 s.
- Code 44 -> circuit open 60 s, no retries, `RATE_LIMITED`; half-open probe after.
- Code 45 -> `DAILY_QUOTA_EXHAUSTED`, never retried, budget exhausted until UTC midnight.
- Code 1070 -> up to 3 jittered retries, then `RATE_LIMITED`.
- 5xx/timeout -> 2 retries, 10 s per attempt; 5 consecutive failures open the breaker 30 s.
- Daily share: free plan stops at 500; `budget_remaining_today` decrements.
- Cache: items 60 s, org 300 s, key includes tenant; identical in-flight loads coalesce.
- Two agents (two runtimes, one Kv) issuing 200 calls stay <= 80/min.
- Every path emits the right `GovernorDecision`.

**Build:** `createGovernor({ kv, clock })` and `createCache({ kv, clock })` implementing core interfaces with only
Kv commands (INCR/EXPIRE, SET NX PX, ZSET leases; no Lua); wire into ZohoClient and the demo tenant
(`demo:{session}` scopes, faults from FakeZoho).

**Out of scope:** UI toggles beyond code 44 and expired token (M4/M7), Prometheus metrics (M7).

**Done when:**

- `pnpm --filter @mb/governor test` green incl. `pnpm --filter @mb/governor exec vitest run -t "code 44"`.
- `pnpm --filter @mb/zoho-inventory test && pnpm lint && pnpm typecheck` green.
- `/security-review` run: no governor bypass, keys tenant-scoped.

`feat(governor): read-through cache with coalescing`.
