# M1 Contract + FakeZoho + MCP (1 day)

**Goal:** the 9 Tier-1 tools over `/mcp` (bearer) and `/mcp/demo` (public, FakeZoho), proven by one contract suite.
`packages/core` and much of `zoho-inventory`, `db`, `apps/api` exist from the initial parallel build: **verify and
complete them**; change `packages/core` only with an ADR-worthy reason.

**Read first:** `packages/core/src/*`, `docs/notes/zoho.md` §4-7, `docs/notes/mcp-v2.md` (all),
`docs/agent-capabilities.md`, `docs/adr/0003-*.md`, `docs/adr/0006-*.md`, existing `packages/zoho-inventory/src/**`.

**Tests first (red, committed before implementation):**

- Contract suite (`packages/zoho-inventory/test/contract.test.ts`), per tool, through an in-process MCP `Client`
  over `handler.fetch`, in both `versionNegotiation` modes (`legacy`, `auto`): valid args -> schema-valid
  `structuredContent`; bad args -> `isError` + `INVALID_INPUT` (never a throw); unknown id -> `NOT_FOUND`;
  result <= 10K tokens; allow-listed fields only; exactly one usage event.
- FakeZoho wire tests: `code != 0`, `page_context`, 401, 429 codes 44/45/1070, 5xx, malformed JSON.
- Unknown tool -> JSON-RPC error `-32602`. `tools/list` order stable. Injection note stays inside `untrusted_text`.
- `docs/mcp-tools.json` staleness test.

**Build:**

- ZohoClient (GET only, `organization_id` on every call, maps errors per notes/zoho.md §7) on the `Governor` interface.
- Mappers with field allow-lists, money in minor units, masking, `untrusted_text`; FakeZoho demo dataset matching
  `DEMO_IDS`.
- The 9 tools with "use when / don't use when" descriptions; sales-order fallback chain per ADR-0006.
- `apps/api`: register via the pass-through `fromJsonSchema` pattern (mcp-v2.md §3); `/mcp` API-key auth; `/mcp/demo`
  60/min per IP; `pnpm gen:tools` from a real `tools/list`.

**Out of scope:** real OAuth (seeded test connection), real governor (pass-through is fine), site pages, evals.

**Done when:**

- `pnpm --filter @mb/zoho-inventory test && pnpm --filter @mb/api test && pnpm lint && pnpm typecheck` green.
- `pnpm gen:tools && git diff --exit-code docs/mcp-tools.json`.
- `npx @modelcontextprotocol/inspector --cli $API_URL/mcp/demo --transport http --method tools/list` shows 9 tools,
  same order twice.
- Fresh Claude Code session after `claude mcp add --transport http mb-demo $API_URL/mcp/demo` answers
  "Is CHAI-250 in stock in Bengaluru and at what price?" with `zoho_get_item`.
