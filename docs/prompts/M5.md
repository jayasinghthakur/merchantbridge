# M5 Docs, evals, ship (1/2 day)

**Goal:** a reviewer can evaluate everything from the README in 5 minutes; evals published; `v0.1.0` tagged.

**Read first:** `README.md`, `docs/agent-capabilities.md`, `docs/integration.md`, `docs/runbook.md`,
`docs/platform-feedback.md`, `docs/adr/*`, `docs/notes/anthropic-mcp.md` §5, `packages/core/src/scenarios.ts`,
`evals/**`, `docs/STATUS.md`.

**Tests first (red):**

- Eval harness unit tests: expected-tool matching is order-insensitive; refusal scenarios fail on any tool call;
  injection scenario fails if the answer follows the planted instruction.
- Doc tests: README links and `docs/` relative links resolve; every tool in `docs/mcp-tools.json` appears in
  `docs/agent-capabilities.md`.

**Build:**

- 15 evals: the 5 scenario cards, 3 refusals, 1 prompt injection, 6 tool-specific (one per tool not covered by a
  card). Runner reuses the playground loop on the in-process MCP client; runs on `claude-haiku-4-5` and
  `claude-sonnet-5-5` (no `temperature` on Sonnet 5.5); writes `evals/reports/<date>.json` + `.md`.
- Fix failing evals by editing tool descriptions first, code second; commit report + description change together.
- README: replace TODO links (live site, demo MCP URL, video), paste dogfood transcripts, "Built with Claude Code"
  PR links. Update CAN/CANNOT with the final tool list and ADR-0006 outcome.
- `examples/python/`: Agent SDK client against `/mcp/demo`, run in CI.
- Record the 2-minute real-OAuth video (human).

**Out of scope:** Tier 2 tools, `/activity`, Proof toggle.

**Done when:**

- `pnpm evals` -> Sonnet >= 90% pass, Haiku published as-is; report committed.
- `pnpm lint && pnpm typecheck && pnpm test && pnpm build` green; CI green.
- A fresh subagent acting as "Razorpay FDE reviewer with 3 minutes" follows the README in a cold incognito session;
  its findings are fixed.
- `git tag v0.1.0` on main after CD deploys.

**Commit:** `test(evals): harness and scenario evals (red)`, `feat(evals): 15 evals on haiku and sonnet`,
`docs: readme, capabilities, integration, runbook`, `chore(release): v0.1.0`.
