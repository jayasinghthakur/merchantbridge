# M4 Site + playground (1 day)

**Goal:** the no-login reviewer journey works on prod: scenario card -> live trace -> answer; code-44 and expired-token
toggles; refusal card; replay fallback.

**Read first:** `docs/PLAN.md` §1 journey + §5, `docs/notes/anthropic-mcp.md` §1-4 and §6, `packages/core/src/http.ts`
(`API_ROUTES`), `packages/core/src/telemetry.ts` (`TraceEvent`, `PlaygroundRequest`, `DEMO_FAULTS`),
`packages/core/src/scenarios.ts`, `apps/web/**` (shell, theme, components exist from the initial build),
`apps/api/src/infra/*` (limits, SSE, Turnstile helpers).

**Tests first (red):**

- `/api/playground`: emits `session` -> `tool_call`/`tool_result` -> `assistant_text` -> `done` for a scenario
  (Anthropic client stubbed); kill switch -> `PLAYGROUND_DISABLED` then replay; 11th question in 10 min from one IP
  -> `RATE_LIMITED`; input > 500 chars -> `BAD_REQUEST`; Turnstile required on first message.
- SSE headers: `X-Accel-Buffering: no`, `Cache-Control: no-cache, no-transform`, 15 s heartbeat, no compression.
- Faults are per session: toggling 44 in session A leaves session B untouched.
- Playwright (`apps/web/e2e`): card -> >= 1 tool step -> answer; toggle 44 -> a `RATE_LIMITED` step visible; refusal
  card -> 0 tool calls; disabled playground -> replay badge.

**Build:** playground engine (in-process MCP client -> `mcpTools` adapter -> `toolRunner`, Haiku 4.5, 6 iterations,
`tool_choice: auto`, `max_tokens` 1024, cached system prompt), recorded replay transcripts, pages `/`, `/playground`,
`/tools` (explorer via `/api/explorer/call`), `/connect` (invite code, DC picker, key shown once, revoke), `/docs`
(CAN/CANNOT, client configs, video slot). Loading/empty/error states, 390 px, light + dark, DEMO DATA badge.

**Out of scope:** `/activity`, extra fault toggles, Proof toggle, `/evals` page.

**Done when:**

- `pnpm --filter @mb/api test && pnpm --filter @mb/web test && pnpm lint && pnpm typecheck` green.
- `pnpm --filter @mb/web e2e` passes against prod (`PLAYWRIGHT_BASE_URL=$WEB_URL`).
- `/verify-prod`: screenshots at 390 and 1440, light and dark, read back with no defects listed.
- `/security-review`: public routes cannot load a live tenant.
