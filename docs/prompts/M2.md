# M2 Zoho OAuth + token vault (1/2-1 day)

**Goal:** a merchant connects a real Zoho org on prod and gets an `mb_live_` key that returns real stock over `/mcp`.

**Read first:** `docs/notes/zoho.md` §2-4 (DC table, OAuth endpoints, limits, error codes), `docs/adr/0004-*.md`,
`packages/auth/src/**` (DC map, state, vault exist from the initial build), `packages/core/src/http.ts`
(`API_ROUTES`, `ConnectErrorReason`, fragment redirect), `packages/core/src/stores.ts`, ADR-0001 results.

**Tests first (red):**

- State: HMAC, single use, 10 min expiry; replayed, expired, tampered and cross-invite states rejected.
- Callback: `accounts-server` not in the DC table -> `unsupported_dc`; `access_denied` -> error redirect;
  `api_domain` mismatch -> table value + warning.
- Refresh: 20 parallel calls with an expired cached token -> exactly 1 token request (ManualClock + MemoryKv).
- 401 -> refresh -> one retry -> success; second 401 or `invalid_code`/`invalid_grant` -> `RECONNECT_REQUIRED` and
  connection `needs_reconnect`.
- Vault round-trip; ciphertext format `v1.<iv>.<tag>.<ct>`; wrong key fails.
- Captured Pino output of a full connect + refresh contains no token, code or client secret.
- API key: shown once, stored as SHA-256, revoked key -> 401.

**Build:** `/oauth/zoho/start` (invite code, DC picker value, 8 scopes, `access_type=offline`, `prompt=consent`),
`/oauth/zoho/callback` (exchange at `accounts-server`, org pick, `ConnectionStore.upsert`, key mint, redirect to
`/connect/success#key=...`), single-flight refresh under `SET NX` with 55 min access-token cache, disconnect + revoke,
Redis `Kv` implementation in apps/api.

**Out of scope:** `/connect` UI polish (M4), OAuth 2.1 on the MCP leg (Tier 3), PKCE.

**Done when:**

- `pnpm --filter @mb/auth test && pnpm --filter @mb/api test && pnpm lint && pnpm typecheck` green.
- `/security-review` findings fixed.
- Human connects the trial org on prod; then
  `claude mcp add --transport http mb-live $API_URL/mcp --header "Authorization: Bearer mb_live_..."` and asks for
  stock of a real SKU: correct answer, one `usage_event` row per call.

**Commit:** `test(auth): oauth state and single-flight refresh (red)`, `feat(auth): zoho oauth and token vault`,
`feat(api): oauth routes and api keys`.
