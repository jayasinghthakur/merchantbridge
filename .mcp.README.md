# Project MCP servers (`.mcp.json.example`)

`.mcp.json.example` is the project-scope MCP config for Claude Code. Copy it to `.mcp.json` to use it. Claude Code
asks you to approve project servers the first time it connects.

| Server       | What it is                                                                                                 | Used by                                             |
| ------------ | ---------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| `mb-demo`    | MerchantBridge's public demo endpoint (demo tenant + FakeZoho, no auth, no real data) over Streamable HTTP | dogfooding the tools; `/milestone` done-when checks |
| `playwright` | [Playwright MCP](https://github.com/microsoft/playwright-mcp), launched with `npx` over stdio              | `/verify-prod` (driving the site, screenshots)      |

## Local vs deployed

The example points `mb-demo` at the local API (`pnpm dev:api`, Fastify on :8787):

```json
"mb-demo": { "type": "http", "url": "http://localhost:8787/mcp/demo" }
```

To use the deployed API, edit the `url` in your `.mcp.json` to `https://<your-api-host>/mcp/demo`. You can also
switch per shell without editing, because Claude Code expands `${VAR:-default}` in `url`:

```json
"mb-demo": { "type": "http", "url": "${MB_DEMO_MCP_URL:-http://localhost:8787/mcp/demo}" }
```

Then start Claude Code with `MB_DEMO_MCP_URL=https://<your-api-host>/mcp/demo claude`.

Without a file, the CLI does the same thing:

```bash
claude mcp add --transport http mb-demo http://localhost:8787/mcp/demo            # local
claude mcp add --transport http mb-demo https://<your-api-host>/mcp/demo          # deployed
```

## Rules

- Never write an `mb_live_…` key into `.mcp.json`. The file is meant to be committed, and `.gitignore` does not
  exclude it. For a real tenant, either:
  - run `claude mcp add --transport http mb-live https://<api>/mcp --header "Authorization: Bearer mb_live_…"` in
    local scope (the default), which stores the key in your user config and not in the repo; or
  - set `"headers": { "Authorization": "Bearer ${MB_LIVE_KEY}" }`, so only the variable name is committed.
- The demo endpoint is rate-limited per IP (60/min). The playground and evals have their own budgets.
